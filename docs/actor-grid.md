# 배우 격자

`/grid?region=korea&mode=easy`와 `/grid?region=hollywood&mode=easy`에서 같은 화면의 한국·헐리우드 편을 연다. 난이도는 `easy`(12회), `hard`(9회)다.

## 생성과 검증

수집된 `data/` 카탈로그가 있는 작업 폴더에서 실행한다.

```powershell
node scripts/build-grid-puzzles.mjs
node scripts/build-grid-play.mjs
node --experimental-vm-modules --test scripts/grid.test.mjs scripts/rank-api.test.mjs scripts/movie-titles.test.mjs
node scripts/build-static-deploy.mjs
node scripts/serve.mjs --port=8891 --root=deploy/noorung-quiz
```

문제 생성 기본값은 지역별 600문제, 배우 후보는 한국 최대 200명·헐리우드 최대 300명이다. `--region=korea|hollywood`, `--count`, `--stars`, `--scan`, `--min-answers`, `--seed`로 조정한다. 같은 입력과 seed는 같은 문제를 만든다. 요청한 문제 수를 채우지 못하면 실패한다.

- 한국: 기존 `quizzes.json`의 관객 100만 이상 영화와 KOBIS 주연·조연 출연진, 검증된 사진을 사용한다. KOBIS의 배우 코드 중복을 처리하던 기존 이름 병합 규칙을 유지한다.
- 헐리우드: 국내 관객 10만 이상 실사 영화에 더해, 북미 흥행 2천만 달러 이상이면서 한국어 제목 매칭 신뢰도가 높은 작품을 포함한다. 국내 흥행 자료가 없는 드라마·로맨스·코미디도 연결에 쓰되, 동명 영화가 잘못 붙은 낮은 신뢰도의 매칭은 확대 대상에서 제외한다. `quiz-overrides.json`의 제외·제목 수정을 반영한다.
- 모든 문제는 여섯 배우가 서로 다르고, 서로 다른 영화 아홉 편으로 완성할 수 있어야 한다. 정답 후보 수 기본 하한은 한국 12개·헐리우드 9개다. 헐리우드의 시리즈별 대규모 출연진이 이 조건에 유리했으므로 후보 개수보다 작품 다양성을 우선한다. 동명 영화로 출연진이 섞이지 않도록 정규화한 한국어 제목이 같은 영화는 제외한다.
- 한국 편은 같은 축의 배우끼리 함께 출연한 경우를 제외하는 기존 조건도 유지한다. 헐리우드 편은 앙상블 출연진의 연결을 위해 이를 허용한다. 질문은 항상 위쪽 배우와 왼쪽 배우의 교차점이다.
- 정답이 많은 조합에 가산점을 몰아주던 방식을 배우별 출제 횟수에 따라 균형을 맞추는 방식으로 바꿨다. 풀이 가능성 검증은 선택 전에 수행한다.
- 헐리우드 배우 인지도는 누적 앙상블 흥행 대신 `imdb-fame.json`의 경력 전체 인지도 값을 사용한다. 출제 후보 배우는 마블·DC 이외 출연작도 최소 세 편 있어야 한다.
- 헐리우드의 모든 문제는 마블·DC 영화 두 편 이하로 완성하는 해답이 존재해야 한다. 실제 플레이에서 그 외 올바른 답을 제한하는 규칙은 아니다. `grid-variety.mjs`가 영화 제목으로 해당 시리즈를 분류하므로 새 시리즈가 추가되면 분류도 갱신한다.
- 헐리우드에서는 한 영화가 전체 문제의 15%를 초과해 정답 후보에 등장할 수 없다. 정답 후보로 가능한 모든 대체 답까지 센다. 배우·영화 출제 빈도를 함께 고려하고, 결과의 정답 목록은 마블·DC 이외 작품을 먼저 보여준다.
- 플레이 중에는 최근 100문제를 피하고, 직전 판 및 최근 다섯 판과 배우가 덜 겹치는 문제를 고른다. 헐리우드에서는 정답 후보 영화의 반복도 함께 줄인다. 지역별 기록을 저장하므로 새로고침과 난이도 변경에도 적용된다. 문제 데이터가 바뀌면 출제 이력만 초기화한다.
- 한국 점수 키 `grid/easy`, `grid/hard`는 유지한다. 헐리우드는 `grid/hollywood-easy`, `grid/hollywood-hard`를 사용한다. 한국어 제목과 영어 원제는 같은 영화로 처리하므로 두 언어로 중복 사용해도 시도를 소모하지 않고 거절한다.

`grid.test.mjs`는 자료가 있을 때 생성된 모든 칸을 원본 출연진과 대조하고, 풀이 가능성·출제 분산·100판 연속 선택을 검사한다. 헐리우드의 마블·DC 의존도와 영화별 15% 상한도 모든 문제에 대해 검사한다. 자료가 없는 체크아웃에서는 해당 통합 검사만 건너뛰고 작은 고정 자료로 생성·선택 알고리즘을 검증한다.

2026-09-21 자료 기준: 한국 600문제 / 192명(기존 300문제 / 97명), 헐리우드 600문제 / 124명. 한국 배우 최대 출제 비율은 32.7%에서 6.2%로 감소했다.

2026-09-22 헐리우드 재조정: 600문제 / 207명. 「어벤져스: 엔드게임」이 답 후보인 문제는 501개(83.5%)에서 90개(15%)로 감소했다.
